## E. 조종기 — 현행 배치 (2026-09-05 실기 검증)

| 스위치 | 채널 | 기능 |
|---|---|---|
| SA | CH5 | ARM |
| **SB** (3단) | CH6 | 비행모드 위/중간/아래 = **Stabilized / Altitude / Position** |
| SC (3단) | CH7 | SF 와 조합해 모드 래치 |
| SD | CH8 | 미매핑 ⛔ 고정익 차단 |
| **SE** | CH9 | **KILL** |
| SF (모멘터리) | CH10 | 래치 트리거 |

**SC + SF 조합**: SC 위 + SF 딸칵 → **Mission** / SC 아래 + SF 딸칵 → **RTL**
SC 중립 복귀 = 즉시 취소, SB 값으로 돌아감.

- [ ] 조종기 배터리 잔량
- [ ] **SA 위(해제) · SC 중립 · SE 위(해제)** 에서 시작
- [ ] 스틱 중립, 스로틀 최하
- [ ] SB 3단 움직여 QGC 에서 모드 3개 바뀌는지 눈으로 확인
- [ ] SC+SF 로 Mission·RTL 걸리고, SC 중립으로 취소되는지 확인 후 **중립으로 둘 것**
- [ ] ⚠️ 조종기를 USB Storage 모드로 켠 적 있으면 **케이블 뽑고 → 전원 OFF → ON** 재부팅
      그 모드에서는 모델이 로드되지 않아 옛 값이 나간다
