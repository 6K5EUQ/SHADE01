## ⚠️ 문제 (심각도 순)

### 1. 🔴 에어스피드 음수 — 고정익 전환 불가

```
airspeed_validated:  평균 -6.4 m/s   범위 -8.4 ~ +12.0
differential_pressure:  평균 -27.7 Pa   범위 -44.1 ~ -18.6  (항상 음수)
```

**공기속도는 음수가 될 수 없다.** 차압이 전 구간 음수라는 건 피토관 배관이
**정압/동압이 반대로 연결**됐다는 뜻이다. 센서 자체는 정상 (`confidence=1.0`, `error_count=0`).

**영향**: 지금은 멀티로터 모드라 비행에 지장 없다. 그러나 **고정익 전환은
에어스피드가 전환 속도에 도달했는지로 판단**한다. 음수면 영원히 조건 미달이거나,
더 나쁘게는 잘못된 값으로 조기 전환해 **실속(stall)** 한다.

**조치**:
1. 피토관 튜브 2개를 **서로 바꿔 연결** (동압 포트 ↔ 정압 포트)
2. 지상에서 `SENS_DPRES_OFF` 영점 재보정 (무풍 상태)
3. 입으로 불어서 **양수**가 나오는지 확인
4. 그 다음에야 전환 비행 계획

관련: [에어스피드 센서 문서](../components/sensors/holybro-airspeed-dronecan/README.md)

### 3. 🟠 197.3초 — 제어 이탈 의심 구간

착륙 직전 급격한 자세 변화:

```
시각      roll    pitch   고도     전류    M2    M3    M4    M5
196.5s   -16.2°    5.4°  -1.60m   73.2A  0.50  0.00  0.96  0.62
197.0s     0.4°  -23.1°  -1.76m   54.7A  0.10  1.00  0.00  0.83
197.5s    45.4°  -41.9°  -1.86m   20.6A  1.00  0.00  1.00  0.00
198.0s    -0.4°  -10.1°  -2.46m   28.8A  0.00  0.81  0.00  0.81
```

**모터 출력이 0.00 ↔ 1.00 사이를 진동**하고 있다. 제어기가 자세를 잡으려
최대·최소를 오가는 전형적인 **제어 포화(saturation)** 패턴이다.
같은 구간 미배분 토크가 0.62까지 올라간다.

**해석 필요** — 로그만으로는 구분이 안 된다:
- **의도한 기동이었나?** (거친 착륙, 급기동 테스트)
- **바람에 밀렸나?**
- **제어 이탈이었나?**

지면 근처(고도 1.8m)라 **지면효과(ground effect)** 로 인한 불안정일 가능성이 높다.
멀티로터가 지면 1~2m에서 자기 후류에 갇히면 이런 진동이 흔하다.

**조치**: 다음 비행에서 **고도 3~5m 이상**으로 올려 같은 현상이 재현되는지 확인.
재현되면 PID 튜닝, 재현 안 되면 지면효과로 결론.

### 4. 🟡 자기계 간섭 — 전류와 강한 상관

```
전류 - 자기장 세기 상관계수: -0.887
자기장 세기: 평균 0.445 G, 범위 0.373 ~ 0.514
```

**전류가 오르면 자기장이 떨어진다** (상관 -0.89는 매우 강함).
전력선이 만드는 자기장이 나침반을 교란하고 있다.

지금은 GPS가 워낙 좋아(위성 29개) EKF가 GPS 위주로 방위를 잡아 문제가 안 드러났다.
그러나 **GPS 품질이 나빠지는 상황에서 방위 오차**로 이어진다.

**조치**:
1. GPS 마스트를 높여 전력선에서 이격
2. 또는 전력선을 꼬아서(twist) 자기장 상쇄
3. `MAG_COMP_TYPE` 전류 보상 활성화 검토

### 5. 🟡 진동 경고 수준 + 클리핑 발생

```
accel_vibration_metric:  평균 2.2, 최대 14.2   (경고선 10)
accel_clipping[2]:  최대 5회   (Z축)
gyro_vibration_metric:  최대 1.19
```

평균 2.2는 양호하나 **피크 14.2가 경고선을 넘고**, Z축 가속도계가 5회 포화됐다.
클리핑은 센서가 측정 범위를 벗어난 것으로, 그동안 EKF가 잘못된 값을 받는다.

**조치**: 프로펠러 밸런싱, FC 방진 마운트 확인. 지금은 경고 수준이라 급하지 않으나
비행마다 추세를 봐야 한다 (진동은 서서히 악화된다).

### 6. 🟡 EKF gravity innovation 초과

```
gravity[1]  최대 4.35      gravity[0]  최대 3.45      (정상 상한 1.0)
```

중력 벡터 추정과 실측 가속도의 불일치. 급기동 중에는 흔한 현상이나,
위 197초 구간과 시점이 겹치므로 **제어 이탈 시 IMU가 흔들린 결과**로 보인다.
클리핑(5회)과도 연관된다.

진동·클리핑을 잡으면 함께 개선될 가능성이 높다. 별도 조치는 불필요.
