## ⚠️ 문제 (심각도 순)

### 1. 🔴 에어스피드 음수 — 영점 오프셋 드리프트

```
airspeed_validated:     평균 -6.4 m/s   범위 -8.4 ~ +12.0
differential_pressure:  평균 -27.7 Pa   범위 -44.1 ~ -18.6  (항상 음수)
SENS_DPRES_OFF:         -4.518 Pa
SENS_DPRES_REV:         0
```

**공기속도는 음수가 될 수 없다.** 센서 자체는 정상이다 (`confidence=1.0`, `error_count=0`).

#### ⚠️ 최초 진단은 틀렸다 — 배관 역결선이 아니다

처음에는 차압이 전 구간 음수인 것을 보고 **피토관 튜브 역결선**으로 판정하고,
튜브를 서로 바꿔 연결하라고 권했다. **틀렸다.**

조종자가 실물로 확인한 결과 (2026-08-24):

> 입으로 불면 **+10~20 m/s 로 정상 상승**한다. 음수는 **가만히 있을 때만** 나온다.

불어서 양수가 나온다는 것은 **동압/정압 배관 방향이 정상**이라는 뜻이다.
튜브를 바꿨다면 오히려 정상인 배선을 망가뜨렸을 것이다.

> 📌 **로그만으로는 구분할 수 없었던 사례.** "차압이 항상 음수" 라는 관측은
> 역결선과 영점 오프셋 양쪽 모두에 들어맞는다. 둘을 가르는 것은
> **불었을 때 부호가 어느 쪽으로 움직이는가** 이며, 그건 실물 테스트로만 알 수 있다.

#### 실제 원인

정지 상태 실측 (2026-08-24, USB 직결):

```
차압 = -0.069 hPa = -6.9 Pa
SENS_DPRES_OFF = -4.518 Pa   ← 보정값이 실제 오프셋보다 작다
남는 오차 ≈ -2.4 Pa
```

에어스피드는 차압의 제곱근에 비례하므로, 작은 음수 차압이 **-2.5 m/s 수준의 음수 속도**로 나타난다.
비행 중에는 진동·기류가 더해져 -27.7 Pa 까지 벌어졌다.

**추정 원인** — 둘 중 하나이거나 둘 다:

- **온도 드리프트** — MS5525DSO 계열은 온도에 민감하다. 비행 중 센서 온도가 **43~50°C** 였는데
  영점 보정을 다른 온도에서 했다면 오프셋이 어긋난다
- **보정 시 바람** — 보정 시점에 차압이 0이 아니었다면 잘못된 값이 저장된다

#### 조치 — 영점 재보정만

**튜브는 건드리지 말 것.** 배관 방향은 정상이다.

1. 피토관 구멍을 막거나 완전 무풍 실내에서
2. FC 전원을 켜고 **5분 이상 대기** — 온도 안정화가 중요하다
3. QGC → Vehicle Setup → Sensors → **Airspeed** 보정
4. 보정 후 정지 상태 airspeed 가 0 근처인지, 불었을 때 양수로 오르는지 확인

관련: [에어스피드 센서](../components/sensors/holybro-airspeed-dronecan/README.md)

### 3. 🟠 197.3초 — 연속 외란으로 회복 여력 소진, 추락

**조종자 증언 (2026-08-22)**: 호버 안정성 테스트로 **스틱은 중립에 두고 손으로 기체를 밀었다.**
자세 회복 능력을 보려던 것. 2~3차례는 괜찮았고 마지막에 요동치며 추락.

이 맥락이 원인 판정을 바꾼다. 로그상 스틱 입력이 전 구간 중립(`roll 0.00 / pitch 0.01`)이라
처음에는 자발적 PID 발산으로 읽었으나, **외란이 손이었으므로 발산이 아니다.**

#### 교란 이벤트 전체 (경사 15° 초과, 총 20회)

제어기는 **13회를 정상 회복**했다. 문제는 마지막 연타 구간이다.

| # | 시각 | 최대경사 | 직전 최대모터 | **회복 여력** | 회복시간 |
|---|---|---|---|---|---|
| 1 | 134.2s | 17° | 0.72 | **0.28** | 0.40s ✅ |
| 7 | 158.8s | 30° | 0.72 | **0.28** | 1.05s ✅ |
| 12 | 185.0s | 30° | 0.75 | **0.25** | 0.70s ✅ |
| 14 | 194.8s | 26° | 0.79 | **0.21** | 0.60s ✅ |
| 16 | 196.1s | 27° | 0.85 | **0.15** | 2.40s ⚠️ |
| 17 | 196.5s | 39° | 0.94 | **0.06** | 1.90s ⚠️ |
| **18** | **197.0s** | **113°** | **1.00** | **0.00** | **추락** ❌ |

`회복 여력 = 1.0 − 최대 모터 출력`. **0.28 → 0.00 으로 계단식 소진**됐다.
마지막에는 모터가 이미 100%라 더 낼 힘이 없었다.

#### 결정적 차이: 교란 간격

```
초반 교란 간격:  1.3s ~ 15.4s   ← 회복 완료 후 다음 타격
194.8s → 195.7s   0.90초
195.7s → 196.1s   0.40초   ← 연타 시작
196.1s → 196.5s   0.40초
196.5s → 197.0s   0.50초
```

**회복에 0.4~1.0초가 필요한데 0.4초 간격으로 밀었다.** 이전 교란을 다 잡기 전에
다음이 들어와 자세 오차가 누적 → 모터 포화 → 제어 불능.

`MPC_TILTMAX_AIR = 45°` 인데 실제 **113°** 에 도달했다는 것이 결정적이다.
제어기가 명령할 수 있는 한계를 넘었다는 뜻 — **물리적으로 밀려난 것**이지
제어기가 만든 자세가 아니다.

#### 기체 성능은 문제 없었다

안정 호버 구간(경사<5°, |vz|<0.3m/s, 61.4초 / 613샘플) 실측:

| 지표 | 값 |
|---|---|
| 4모터 평균 | **58.7%** |
| 중앙값 | **62.2%** |
| PX4 `hover_thrust_estimate` | **62.1%** |
| 최대 모터 평균 | 64.9% → **여유 35.1%** |
| 모터별 편차 | 57.4 / 60.0 / 58.6 / 59.0% — **무게중심 양호** |

호버 62%, 여유 35%는 이상적인 50~60%보다 약간 높으나 **정상 범위**다.
단발 외란에는 충분했고 실제로 13회를 회복했다. 경량화가 급한 상황이 아니다.

배터리도 원인이 아니다 — 셀 전압이 100s 3.93V → 197s 3.77V 로 0.16V 강하에 그쳤고,
소모는 1179mAh / 16000mAh (7.4%) 였다.

#### 잘한 판단

197.5s 에 **스로틀을 -1.00 (최하)로 내렸다.** 추력이 빠지며 진동 에너지가 줄어
198.0s 에 자세가 회복됐고, 하강률 -1.46 m/s 로 비교적 안전하게 내려앉았다.
그대로 붙잡고 있었으면 더 나빴을 것이다.

#### 조치

**테스트 방법 수정 — 이것이 핵심이다**
- 교란 **간격 3초 이상**. 완전 회복(경사 <5°)을 눈으로 확인한 뒤 다음 타격
- **고도 5m 이상**에서 수행. 회복 실패 시 여유 확보
- 경사 **30° 초과 시 즉시 중단**하고 착륙

**착지 손상 점검** (199.97s 지면 접촉, 하강률 -1.46 m/s)
- 랜딩기어·동체 균열
- 프로펠러 손상, 모터 마운트 헐거움

### 4. 🟡 자기계 간섭 — 전류와 강한 상관

### 5. 🟡 진동 경고 수준 + 클리핑 발생

```
accel_vibration_metric:  평균 2.2, 최대 14.2   (경고선 10)
accel_clipping[2]:  최대 5회   (Z축)
gyro_vibration_metric:  최대 1.19
```

평균 2.2는 양호하나 **피크 14.2가 경고선을 넘고**, Z축 가속도계가 5회 포화됐다.
클리핑은 센서가 측정 범위를 벗어난 것으로, 그동안 EKF가 잘못된 값을 받는다.

**조치**: 프로펠러 밸런싱, FC 방진 마운트 확인. 지금은 경고 수준이라 급하지 않으나
비행마다 추세를 봐야 한다 (진동은 서서히 악화된다).

  올리면 노이즈가 증폭된다. **에어스피드부터 고치고, 안정 호버를 재확인한 뒤에** 검토한다.

## 참고: FC 발열 — 정상

비행 중 6C Mini 케이스가 뜨겁게 느껴졌으나 **이상 없다**.

```
IMU 온도    61.2 → 61.6°C   (107초간 +0.4°C)
기압계      63.1 → 63.4°C   (+0.3°C)
5V 전원     4.94 ~ 5.06V     안정
```

- **온도가 오르지 않는다** — 이미 열평형. 과열이면 계속 상승한다
- **STM32H743 정격 상한 85°C** — 60°C 대는 정상 동작 범위
- **Pixhawk 는 IMU 를 일부러 데운다** — 온도 변화가 자이로 드리프트를 만들기 때문에
  히터로 일정 온도를 유지한다. 60°C 근처는 설계된 목표 온도다

5V 도 4.94~5.06V 로 안정 — [PM08](../components/power/holybro-pm08-can/README.md) 5.3V 공급이 정상 작동 중이다.

> 다만 **배터리 50.9°C 는 높은 편**이다. 78A 를 뽑았으니 예상 범위이나
> LiPo 는 60°C 를 넘으면 위험하다. 다음 비행 후 배터리도 만져볼 것.
