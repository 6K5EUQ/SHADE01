### 1-2. 🟠 배터리 잔량 표시가 부정확하다 — 캘리브레이션

**증상**: 충전기로 80% 충전했는데 FC 에 연결하면 **100% 로 표시**된다.

```
BAT1_V_CHARGED   4.05 V/셀     ← LiPo 완충은 4.20 V
BAT1_V_EMPTY     3.60 V/셀
BAT1_R_INTERNAL  -1.0          ← 미설정
```

**원인 ①** — `BAT1_V_CHARGED = 4.05` 가 실제 완충(4.20V)보다 낮다.
80% 충전 상태가 약 4.0V/셀인데 PX4 는 4.05 를 100% 로 보므로 **거의 만충으로 판단**한다.

> ⚠️ **초판 정정**: `BAT1_R_INTERNAL = -1.0` 을 "미설정" 이라 적었으나 **틀렸다.**
> PX4 에서 **-1 은 "자동 추정"** 이며, 이미 올바른 설정이다. 비행 중 실시간으로 계산해 쓴다.

**부하 시 전압 강하** (참고):

```
전류 <5A 구간   22.83 V → 22.42 V   (0.41 V 강하)
비행 중 최저     21.86 V             (부하로 1.0 V 추가 강하)
```

로그 3개로 내부저항을 역산하면 **셀당 약 0.0021 Ω** 으로 일관된다
(log_94 0.0020 / log_91 0.0022 / log_85 0.0022, R² 0.70~0.81).
6S 16000mAh 대용량 LiPo 로는 타당한 값이다.

**그래도 고정값을 넣지 않는다.** 내부저항은 온도·충전상태·노화에 따라 변하는데
자동 추정은 그걸 실시간 반영한다. R² 가 0.70~0.81 인 것도 전압 강하가 내부저항만으로
설명되지 않는다는 뜻이다(방전에 따른 하락이 섞여 있다). `-1` 을 유지한다.

#### ✅ 조치 완료 (2026-08-25)

```
BAT1_V_CHARGED   4.05 → 4.20     ← FC 에 반영, 재조회 검증됨
BAT1_R_INTERNAL  -1.0 유지       ← 자동 추정
```

**검증 방법**: 다음에 충전기로 80% 충전한 배터리를 연결했을 때
**80% 근처로 표시되는지** 확인한다. 4.05 일 때는 100% 로 나왔다.

### 2. 🟠 모터 M2 가 유독 힘을 더 쓴다 — 신규

안정 호버 구간(경사<5°, |vz|<0.3, 998샘플) 실측:

| 모터 | 출력 |
|---|---|
| M1 | 58.5% |
| **M2** | **71.7%** |
| M3 | 57.9% |
| M4 | 58.0% |

**M2 만 13.8%p 높다.** 나머지 셋은 0.6%p 안에 모여 있다.

8/22 에는 편차가 **2.6%p** 였다(57.4/60.0/58.6/59.0). 그때는 "무게중심 양호"로 판정했다.

#### ✅ 원인 확인됨 — M2 프로펠러 끝 손상 (2026-08-25)

**M2 프로펠러 끝이 갈려 있었다.** 조종자 실물 확인.

인과가 맞는다: 프롭이 손상되면 추력이 줄고, 제어기는 자세를 유지하려
**그 모터의 회전수를 올려 보상**한다. 결과가 71.7% 다.
평균 전류 상승(39.2 → 53.4 A)에도 기여했을 것이다.

**조치**: 프로펠러 교체. 교체 후 다음 비행에서 **모터 편차가 2~3%p 로 돌아오는지** 확인하면
원인이 확정된다. 안 돌아오면 무게중심·모터 자체를 봐야 한다.

한 모터가 71.7% 를 쓰면 **그 모터의 여유가 28%뿐**이다. 외란이 그쪽으로 오면 먼저 포화된다.
호버 평균은 61.5%, 최대 모터 기준 여유는 28.1% 로 8/22(35.1%)보다 줄었다.

> 8/22 리포트의 [197초 추락](2026-08-22-log85-first-hover.md#3--1973초--연속-외란으로-회복-여력-소진-추락)이
> 회복 여력 소진으로 일어났다. 여유가 줄어든 지금 같은 상황이 오면 더 빨리 한계에 닿는다.

**확인 순서**: 프로펠러 육안 → 무게중심 → M2 모터 발열·회전 저항.
