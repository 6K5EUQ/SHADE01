## 3. 문제

### 🟡 전류 — 이번 세션의 실질 위험

`09_38_28` (453초) 실측:

```
평균 44.2 A   최대 66.8 A   소모 5570 mAh
>45A  312회, 누적 269.6초, 최장 연속 24.0초
>60A    6회, 누적   1.6초
```

**453초 중 270초(60%)를 XT90 연속 정격 45A 위에서 보냈다.** 최장 24초 연속.
`09_17_02`(174초)도 최대 60.2A였다.

- 소모 5570 mAh = 16000 mAh 팩의 **34.8%**. 분당 약 738 mAh
- 이 속도면 저전압 RTL(15%)까지 **약 11.5분**
- 셀당 최저 **3.66V**, 전압 강하 1.67V — 부하 시 강하가 크다

**커넥터 교체(XT120/AS150)가 권고가 아니라 필요 항목이 됐다.**

### 🟡 EKF 이상값 — 항목이 늘었다

| 항목 | 최대 |
|---|---|
| `gravity[1]` | 4.49 |
| `mag_field[0]` | 3.95 |
| `mag_field[2]` | 3.38 |
| `airspeed` | 2.63 |
| `gravity[0]` | 1.90 |
| `mag_field[1]` | 1.77 |

test ratio > 1.0 은 센서 불일치다. **자기장 3축이 전부 뜬다** — 전력선 간섭이
유력하다. 전류가 44A 평균으로 흐르는 것과 무관하지 않다.

`gravity` 이상은 가속도계–중력 벡터 불일치로, 진동이나 캘리브레이션을 본다.

### ⚪ 고도 음수 — 미션에는 영향 없다 (해소)

짧은 지상 테스트 로그들이 음수 고도(-0.1 ~ -15.6m)로 찍힌다. 파고든 결과
**미션에는 영향이 없다.**

GPS와 EKF 추정은 **0.1m 이내로 일치**한다(둘 다 26.1~30.3m AMSL). 문제는 기압계로,
GPS보다 약 **14m 높게** 읽는다. EKF 원점 `ref_alt` 가 그 값(41.45m)으로 잡혀
로그의 상대고도가 음수로 나온다.

**미션은 `ref_alt` 가 아니라 홈을 기준으로 한다:**

```
ref_alt  = 41.45 m AMSL   ← 로그 z 의 기준 (기압계 오염)
home_alt = 26.16 m AMSL   ← 미션 GLOBAL_REL_ALT 의 기준 (정상)
```

홈 기준으로 다시 계산하면 +0.8m 로, 지면 근처에서 짧게 뜬 것과 맞는다.
`valid_alt=1`, `manual_home=0` — 홈이 자동으로 제대로 잡혔다.

⚠️ 다만 **기압계가 GPS보다 14m 높게 읽는 것은 사실**이다. `EKF2_HGT_REF=1`(기압 기준)
이라 GPS 없이 뜨면 고도 기준이 그만큼 어긋난다. 실내·GPS 없는 Altitude 모드에서 주의.

### ⚪ 에어스피드 음수 — 오탐

분석기가 "역결선 의심" 으로 표시하나 **오탐이다.** `SENS_DPRES_OFF=-4.52` 영점
오프셋 때문이고 **배관은 정상**(불면 양수). 튜브를 건드리지 말 것.
다만 **천이 전에는 영점 재보정이 필수**다.
