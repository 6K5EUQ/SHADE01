**PC 의 사본은 이제 작업 사본이다.** 지워도 서버에 남는다 — 다만 지우기 전에는
반드시 위 대조를 다시 돌려라 (아래 명령).

```bash
# 서버와 대조 — 출력이 비어 있어야 안전하다
# 양쪽 다 "해시<공백>이름" 한 칸으로 맞춘다. md5sum 은 공백을 두 칸 쓰므로
# 한쪽만 정규화하면 전부 불일치로 나온다 (실제로 겪었다).
norm() { awk '{n=$NF; sub(/.*\//,"",n); print $1" "n}'; }

find ~/SHADE01/logs -name '*.ulg' -exec md5sum {} \; | norm | sort > /tmp/pc.hn
ssh ku@ku-labserver 'cd ~/shade01-data/logs && md5sum *.ulg' | norm | sort > /tmp/srv.hn

comm -23 /tmp/pc.hn /tmp/srv.hn      # PC 에만 있는 것 — 비어야 한다
comm -13 /tmp/pc.hn /tmp/srv.hn      # 서버에만 있는 것 (다른 PC 로그이므로 정상)
```
