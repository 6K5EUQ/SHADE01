    상시 주의 판정과 무관 · 매 비행 동일

    같은 점검을 터미널에서

    판정은 같은 코드가 낸다. 화면이 안 열리는 곳에서도, 스크립트 안에서도 쓸 수 있다.

    ./shade01 test
    판정만. 종료코드 0 GO · 1 NO-GO · 2 확인 후 판단
    ./shade01 test -v
    정상·참고 항목까지 전부
    ./shade01 test -t 10
    텔레메트리를 10초 모은다 (기본 6초)
    ./shade01 test --json
    판정 한 벌을 JSON 으로
    ./shade01 test --stream
    끝나는 묶음부터 NDJSON 으로 — 이 화면이 쓰는 것
    ./shade01 test --conn udpout:100.117.47.105:14550
    다른 PC 에 꽂힌 FC 를 직접 지정

    연결 순서는 시리얼 직결 → 이 PC 의 브리지 → 다른 PC 의 브리지 다. FC 시리얼은 한 번에 하나만 쓰므로, 누가 쥐고 있으면 도구가 점유자를 이름으로 대 준다.
