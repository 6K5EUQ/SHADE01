## 🔶 확인 필요 (스펙 불일치)

- **모델명 vs 실측 KV**: 제품명/모델은 "M4112KV460"이나, Technical Parameters 표에는 KV=**400**으로 기재되어 있음. 제조사 표기 관행상 모델명의 "KV460"은 시리즈/버전 표기이고 실제 권선 KV값은 400일 가능성이 있음 — 실물 라벨 또는 제조사 문의로 교차 확인 권장.
- **[MFE ESC 650 (6S 50A)](../../esc/mfe-esc-650-50a/README.md) 문서의 모터 호환 경고**와 대조: 해당 ESC는 "MFE 5008 KV400 모터 전용으로 최적화"라고 명시되어 있었음. 본 모터의 실측 KV가 400으로 숫자는 같지만, 프레임 표기("5008" vs "M4112", 49.8×27mm)가 달라 **동일 모델인지는 확인되지 않음** — 전류 정격(둘 다 50A)이 우연히 맞아떨어질 뿐일 수도 있으므로, 이 문서의 다른 수치가 일치한다고 해서 "정상 매칭이 확정됐다"고 단정하지 말 것. 실물 라벨 대조 또는 제조사 문의 전까지는 **불일치 가능성을 열어둔 상태**로 취급.
- 본 모터의 권장 ESC는 **50A**로 명시되어 있고 보유 기체의 VTOL ESC도 6S 50A([MFE ESC 650](../../esc/mfe-esc-650-50a/README.md))라 **전류 정격 숫자는 같음**. 다만 이는 "같은 모터라서 맞다"는 확인이 아니라 단순히 두 스펙표의 전류값이 같다는 것만 확인된 상태이며, 실물이 동일 모델인지는 위 항목과 마찬가지로 미확인.
