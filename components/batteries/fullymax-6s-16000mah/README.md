# Fullymax 22.2V 6S 16000mAh 25C 리튬폴리머 배터리 (XT90S)

Fullymax(풀리맥스)의 산업용 6S LiPo 배터리. [Striver Mini VTOL](../../../airframes/striver-mini-vtol/README.md)의 [배터리 캐빈](../../../airframes/striver-mini-vtol/README.md#부위별-사진-자료)에 장착되는 메인 동력 배터리이며, PNP 옵션에는 미포함이라 별도 구매한 부품.

- 제조사: Fullymax (풀리맥스)
- 제품명: 풀리맥스 22.2V 6S 16000mAh 25C 리튬폴리머 배터리 (XT90S)
- 판매처: XCOPTER (엑스캅터), 250,000원 (2026-08-03 확인)
- 원산지: 중국
- 용도: 메인 추진 전원 — [PM08-CAN](../../power/holybro-pm08-can/README.md) → [PDB 300A](../../power/holybro-pdb-300a-side-entry/README.md) → 각 ESC로 공급

## 방전 전류 vs 시스템 전류 상한 대조

| 항목 | 값 |
|---|---|
| 배터리 연속 방전 한계 | 25C × 16Ah = **400A** |
| 배터리 순간(3초) 방전 한계 | 50C × 16Ah = **800A** |
| [PM08-CAN](../../power/holybro-pm08-can/README.md) 연속 전류 정격 (시스템 병목) | 200A |
| Striver 4+1 이론상 피크(VTOL 4×50A + 크루즈 100A) | 300A |

배터리 자체의 방전 한계(연속 400A)는 시스템 어느 구간보다 커서 배터리가 병목이 되지는 않는다. 실제 시스템 전류 상한은 [PM08-CAN 문서](../../power/holybro-pm08-can/README.md#️-전류-용량-주의)에서 다룬 대로 파워모듈의 연속 200A가 병목이며, 배터리는 이 조건을 충분히 여유 있게 충족한다.

## 커넥터 궁합

배터리 출력 커넥터는 **XT90-S**(스파크 방지형). [PM08-CAN 문서](../../power/holybro-pm08-can/README.md#전력-경로-inline-passthrough)에 따르면 PM08의 배터리 IN 커넥터 옵션은 XT90 / Tinned Wire(피복 벗긴 선) / XT90+링터미널 중 선택인데, PM08 문서에서 이미 "XT90은 연속 45A로 주 간선에는 부족, 링터미널+8AWG 권장"이라고 지적한 바 있음. 본 배터리의 XT90-S 커넥터를 그대로 PM08 IN에 연결하면 **배터리~PM08 구간이 XT90 정격(연속 45A)으로 제한**되므로, 실사용 전류가 45A를 초과할 경우(Striver 시스템은 최대 200A까지 가능) 커넥터 교체 또는 링터미널 변환 케이블이 필요함.

### 암수(성별) 대조 — 확인됨 (제품 사진 판독, 2026-08-08)

| 쪽 | 커넥터 | 성별 | 판독 근거 |
|---|---|---|---|
| 본 배터리 | XT90-S | **수(male, 플러그)** | [images/02-features-and-specs.png](images/02-features-and-specs.png) 스펙표 배터리 사진 — 마감면에 원통형 불릿 핀 2개 돌출, 하우징에 녹색 마킹(스파크 방지형 식별) |
| [PM08-CAN](../../power/holybro-pm08-can/README.md#보유-개체-커넥터-실물-사진-확인-2026-08-04) BAT IN | XT90 | **암(female, 소켓)** | PM08 제품 사진 — 마감면이 평평하게 닫혀 있고 핀 돌출 없음, 전선 쪽에 수축 슬리브 칼라 |

**→ 배터리(수) ↔ PM08(암), 그대로 체결 가능.** XT90 계열 관행(배터리=수, 부하 측=암)과 일치하며, 배터리 측 노출 단자가 수가 아닌 구성이므로 단락 위험 측면에서도 정상 방향.

XT90-S의 프리차지 저항은 **수 커넥터 쪽에 내장**되어 있어, 상대가 일반 XT90 암이어도 스파크 방지 기능은 정상 작동함.

> ⚠️ 암수가 맞는다는 것은 "물리적으로 꽂힌다"는 뜻일 뿐, 전류 용량과는 무관하다. 이 구간의 연속 45A 병목은 그대로 남아 있음(위 문단 및 [PM08 전류 용량 주의](../../power/holybro-pm08-can/README.md#️-전류-용량-주의) 참조).
>
> 판독에 사용한 원본 이미지 해상도가 낮음(PM08 사진 448×415px, 배터리 커넥터는 스펙표 내 소형 썸네일). 형상 판정 자체는 명확했으나, 실물 보유 시 육안 재확인 권장.

## 리튬배터리(Li-Po) 사용 주의사항 (원문 요약)

**사용 시**
1. 비행 전 배터리를 완충 후 셀별 전압 밸런스를 체크할 것 (셀 간 밸런스가 무너지면 화재 원인이 될 수 있음)
2. 타 배터리와 혼용해서 사용하지 말 것 (브랜드, 전압, 폴리티(?), 용량을 맞춰 안전하게 비행)
3. 배터리를 끝까지 방전하지 말 것 (배터리를 안전하고 오래 사용하려면 셀별 전압을 3.5V 이상 남겨두고 사용 권장, 과도한 방전은 배터리 수명을 단축시킬 수 있음)

**충전 시**
1. 충전 중에는 절대 자리를 비우지 말 것 (충전 중 사망사고나 화재 발생 징후가 보일 경우 즉시 충전을 중단할 것)
2. 충전 후 배터리는 즉시 분리할 것 (위험요소 예방)
3. 배터리 셀의 전압 차이가 심할 경우 충전을 중단할 것 (전압 차이가 많이 나거나 용량이 50% 이상 차이날 경우 전류 폭발이 있을 수 있으니 주의)
4. 과충전 절대 금지 (적합한 충전기를 사용하지 않아 과충전되었을 경우 100% 폭발할 수 있으니 주의)
5. 충전은 환기가 잘 되는 장소에서 진행할 것 (밀폐된 공간이나 밀집된 장소는 피하고, 가능하면 아이 또는 동물이 없는 통풍이 원활한 공간에서 충전)
6. 고온 환경에서 장시간 방치하거나 충전하지 말 것 (자동차 안에서 충전하며, 직사광선이나 차량 내부와 같이 온도가 급격히 상승할 수 있는 장소는 반드시 피할 것)
7. KC 인증 충전기를 사용해 주세요 (과충전 보호 회로가 탑재된 KC 인증 마크 충전기를 사용해 주세요, 검증되지 않은 충전기 사용 시 배터리 손상 및 화재발생 위험이 있을 수 있습니다)

**보관 시**
1. 상온 22℃~28℃ 사이에서 보관해주세요, 습하거나 높은 온도 40℃ 이상 또는 −10℃ 이하에서는 배터리 손상이 발생합니다.
2. 외관상 휘어지거나, 찌그러지거나, 부풀 경우 보관 또는 충전을 하지 말 것 (형태 위험합니다)
3. 장기보관 시 배터리 용량의 30%~50% 안 충전하여 보관합니다 (완충상태 장기보관은 배터리를 무겁게 하며, 적은 용량으로 보관 시 자연방전으로 셀이 손상될 수 있습니다)
4. 보관 시 절대 드론에 장착한 상태로 보관하지 마세요 (드론이 파손 시 배터리도 전류가 흐르기 때문에 장기간 방치 시 셀이 손상되어 재사용이 불가능하게 될 수 있습니다)
