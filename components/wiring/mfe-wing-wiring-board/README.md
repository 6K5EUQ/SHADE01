# MFE-Striver Wing Terminal (FDZ Mini, 35cm) — 날개 배선보드

Makeflyeasy(MFE)의 날개 전원/신호 분배 단자대. [Striver Mini VTOL](../../../airframes/striver-mini-vtol/README.md)의 [어댑터/에일러론 서보 캐빈](../../../airframes/striver-mini-vtol/README.md#구조캐빈별-사양)에 장착되어, 날개-동체 9+2 커넥터에서 들어온 전력/신호를 로터(VTOL 모터) 및 에일러론 서보로 분배하는 역할. 좌/우 날개에 각 1개씩, 보유 기체(PNP 옵션)에 **2개 포함**되어 있다.

사진에는 **동일 설계의 보드 2장이 겹쳐서** 촬영되어 있다(좌/우 날개용 2개 세트 = 구성표의 "Wing terminal ×2"). 별개 기능의 두 유닛이 아니라 같은 물건 2개다 — 앞쪽 보드가 뒤쪽 보드의 단자 일부를 가리고 있어 개수가 달라 보일 뿐이다.

### 보드 구성 (확대 판독, 2026-08-14)

```
      [−]        (M4 스크류터미널)        [+]        ← 전력 분배
   ┌───────────────────────────────────────────┐
   │        S1      S2      S3      S4         │  ← 상단 라벨
 P │        ▯▯      ▯▯      ▯▯      ▯▯         │ P
 W │      ┌────────────────────────────┐       │ W
 M │      │  ○ ○ ○ ○ ○ ○ ○ ○  (핀헤더) │       │ M
+5V│      └────────────────────────────┘       │ +5V
GND│        ▯▯      ▯▯      ▯▯      ▯▯         │ GND
   │        S1      S2      S3      S4         │  ← 하단 라벨
   └───────────────────────────────────────────┘
   좌측 행라벨                          우측 행라벨 (동일)
```

| 구역 | 확인 내용 |
|---|---|
| 상단 스크류터미널 | **`−` / `+` 2개소** (M4 추정, 은색 압착 러그 + 십자 나사). 보드 실크에 흰색 `+` 마크 대형 인쇄. 굵은 적/흑 14AWG 실리콘 와이어 결선 — **VTOL 모터 전원 분배** |
| 신호 핀헤더 | 중앙 8핀 헤더. **`S1 S2 S3 S4` 라벨이 상단·하단 양쪽에 인쇄**됨 (같은 4채널을 위아래에서 접근) |
| 행 라벨 | **`PWM` / `+5V` / `GND`** 3행 — 보드 **좌측·우측 양쪽에 동일하게 인쇄**되어 있어 3핀 서보 커넥터 방향을 좌우 어느 쪽에서도 판독 가능 |
| 좌측 3핀 커넥터 ×2 | 검정 하우징 표준 서보 커넥터(암) — 흑/백 트위스트 페어. 채널 신호 인출용 |
| 링터미널 | 케이블 다발 중 금색 링터미널 1개 확인 — 전력선 끝단 |
| 보드 실크 각인 | 좌측 세로로 `...V1.2` 형태의 리비전 표기 확인 (전체 문자열은 해상도 한계로 미판독) |

### 핀 배치 — 표준 3열 서보 배열

`PWM / +5V / GND` 3행 × `S1~S4` 4열 구조. **표준 서보 커넥터를 채널당 1개씩 꽂는 배열**이며, 행 순서가 `PWM(신호) → +5V → GND`이므로 일반적인 JR/Futaba 서보 커넥터 배열(신호-전원-접지)과 일치한다.

> ⚠️ 위 ASCII 도해의 상하 배치는 사진의 원근을 편 것이며, **실물의 물리적 상하 방향은 장착 후 실크스크린으로 재확인할 것.**

## 배선 방법 (Striver 기체 기준)

```
                    동체 (Fuselage)
   [PDB 300A] ──전력──┐        [FC 6C Mini] ──신호──┐
                      │                             │
                      ▼                             ▼
              날개-동체 9+2 커넥터  (A1/A2 = Power+/−, 1~9 = 신호)
                      │
        ══════════════╪══════════════  ← 날개 분리선
                      ▼
        ┌─────── Wing Terminal (본 보드) ───────┐
        │                                        │
   [−][+] 스크류터미널                    S1~S4 핀헤더
        │                                        │
        ├─► 전방 로터 ESC 전원                   ├─► 전방 로터 ESC 신호
        └─► 후방 로터 ESC 전원                   ├─► 후방 로터 ESC 신호
                                                 └─► 에일러론 서보 (PWM/+5V/GND)
```

### 1. 전력 계통 — 스크류터미널 `−` / `+`

날개 커넥터 **A1(Power+) / A2(Power−)** 로 들어온 VTOL 모터 전원을 보드의 `+`/`−` 스크류터미널로 받아, 그 날개에 달린 **VTOL ESC 2개**([MFE ESC 650](../../esc/mfe-esc-650-50a/README.md))로 분배한다.

- 동봉 와이어는 **14AWG 실리콘**, 끝단 일부는 **링터미널** 압착 상태 → 스크류터미널에 나사로 체결
- ESC 전원 입력도 `OT2.5-4 링터미널`이므로 **이 구간은 링터미널끼리 나사 체결로 해결** — 동체측 [PDB↔ESC XT90 불일치 문제](../../power/holybro-pdb-300a-side-entry/README.md#-pdb--esc-커넥터-불일치--무개조-연결-불가-2026-08-08-확인)와 달리 **날개 안쪽은 커넥터 가공이 필요 없다**
- ⚠️ **극성 필수 확인** — 실크의 `+`/`−` 각인과 적(+)/흑(−) 배선을 대조할 것

### 2. 신호 계통 — S1~S4 핀헤더

`PWM / +5V / GND` 3핀 1조가 채널이며, 표준 서보 커넥터를 그대로 꽂는다.

| 부하 | 커넥터 | 주의 |
|---|---|---|
| VTOL ESC ×2 | 3핀 하우징, **흰(Signal) + 검(GND), 가운데 빈 슬롯** ([ESC 커넥터 실측](../../esc/mfe-esc-6s-100a/README.md#시그널-커넥터-실물-확인-2026-08-14)) | 가운데가 비어 **뒤집어도 꽂힌다.** 흰색을 `PWM` 행에 맞출 것 — 뒤집으면 모터가 안 돎 |
| 에일러론 서보 ×1 | 표준 3핀 (신호/+5V/GND 전부 결선) | 3핀 모두 사용. **뒤집어 꽂으면 서보 손상** |

> ⚠️ ESC와 서보는 커넥터 외형이 같지만 **결선이 다르다**(ESC는 2핀만, 서보는 3핀 전부). 서보는 역삽 시 실제로 타므로 `+5V` 행 위치를 반드시 실크로 확인하고 꽂을 것.

### 3. 좌/우 날개 채널 대응

보드 자체는 좌/우 동일 부품이나, **동체측에서 오는 신호가 다르다**:

| 날개 | ESC 신호 (9핀 커넥터) | 서보 신호 |
|---|---|---|
| 좌 | 5번=ESC A3, 6번=ESC A2 | 7번=Servo M1 |
| 우 | 5번=ESC A1, 6번=ESC A4 | 7번=Servo M5 |

즉 **보드는 호환되지만 장착 후 모터 회전 방향/채널 매핑은 좌우가 다르다.** 조립 시 좌우를 바꿔 달면 FC 채널과 어긋난다.

### 4. 작업 순서 권장

1. 날개 커넥터 9+2핀 **1:1 대응 확인** (원문 경고 — 단락 방지)
2. 전력: 링터미널 → `+`/`−` 스크류터미널 나사 체결, 극성 확인
3. 신호: ESC 2개 + 서보 1개를 S1~S4 중 배정 채널에 꽂되 **흰색=PWM 방향** 확인
4. **전원 인가 전** 멀티미터로 `+`↔`−` 단락 여부 점검
5. 프로펠러 탈거 상태로 모터 회전 방향·채널 매핑 확인
