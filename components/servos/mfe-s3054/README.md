# MFE 3054 — 디지털 서보 (풀메탈 기어, 항간섭)

Makeflyeasy(MFE)의 풀메탈 기어 디지털 서보. [Striver Mini VTOL](../../../airframes/striver-mini-vtol/README.md)의 조종면(에일러론, 수직/수평 꼬리) 구동에 사용되며, 보유 기체(PNP 옵션)에 **5개 포함**되어 있다.

- 제조사: Makeflyeasy (MFE)
- 제품명: "Makeflyeasy S3054 Digital Servo Full Metal Teeth Anti-interference"
- 모델: MFE 3054
- 원산지: 중국(Made in China)
- 판매처: uavmodel.com (UAVMODEL CO., LIMITED, Hong Kong), 단가 $14.00 (2026-08-02 확인)
- 용도: Striver Mini VTOL 조종면 구동 (좌/우 에일러론, 수직꼬리, 좌/우 수평꼬리)
- 장착 위치: [어댑터/에일러론 서보 캐빈](../../../airframes/striver-mini-vtol/README.md#부위별-사진-자료), [수직 꼬리](../../../airframes/striver-mini-vtol/README.md#부위별-사진-자료), [수평 꼬리](../../../airframes/striver-mini-vtol/README.md#부위별-사진-자료)

## 특징 (원문 요약)

- **Super torque(고토크)**, **Rapid response(고속 응답)**, **Anti-scald and anti-shake(내열/무진동)**
- 고성능 MCU 채택, 소프트웨어 필터링 알고리즘 및 하드웨어 필터링 회로를 심층 최적화하여 강력한 항간섭(anti-jamming) 성능 확보. 산업용 고정익기의 서보 안전 요구사항을 충족.
- 고정익 실제 장착 테스트를 통해, 1W급 디지털 전송(digital transmission) 및 맵 전송(map transmission)에 간섭받지 않으며 러더(조종면) 떨림/rattling 현상 없음을 확인
- **High accuracy / High speed**: 고정밀 전위차계(potentiometer) 사용, 고품질 칩 선별로 정밀도와 응답속도 확보, 강한 항간섭 성능
- **High stability / Long lasting**: 올메탈 기어, 강력한 파워, 내열(anti-scorching)/무진동(anti-shaking) 정밀도, 긴 수명, 저소음, 내구성, 기어 마모(sweeping teeth) 없음
- **High demands / High standards**: 엄격한 품질 관리, CE 국제 안전표준 인증 준수, 장시간 부하 피로 테스트를 통해 안정적이고 신뢰할 수 있는 비행 품질 보증

## 보유 수량 및 용도 (SHADE 기체)

PNP 옵션 기준 **5개 포함**. 물리적으로 장착되는 조종면(좌/우 에일러론, 수직꼬리, 좌/우 수평꼬리)은 [Striver 기체의 캐빈 구조](../../../airframes/striver-mini-vtol/README.md#구조캐빈별-사양)로 확인되나, 아래 채널 번호는 **Pixsurvey V3 FC 기준 참고자료**이며 SHADE 보유 기체의 실제 FC는 [Holybro Pixhawk 6C Mini](../../fc/holybro-pixhawk-6c-mini/README.md)로 확정되어 있어 채널 체계(MAIN OUT/AUX OUT)가 다르다. 아래 표는 "어느 조종면에 서보가 있는지"만 참고하고, 채널 번호는 실제 배선 시 새로 매핑할 것.

| 채널 (Pixsurvey V3 기준, SHADE 미적용) | 조종면(물리적 위치) |
|---|---|
| M1 | 좌측 에일러론 |
| M5 | 우측 에일러론 |
| M4 | 수직꼬리 |
| M2 | 좌측 수평꼬리 |
| M6 | 우측 수평꼬리 |

> 좌우 수평꼬리는 독립 서보 제어로, 한쪽 서보 고장 시에도 귀환 가능하도록 설계됨 ([수평 꼬리 구조](../../../airframes/striver-mini-vtol/README.md#부위별-사진-자료) 참조).
