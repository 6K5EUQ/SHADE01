# 박서 스위치 매핑 — 채널 배정과 RC 값

[Boxer](README.md) 물리 스위치가 어느 채널로 나가고 FC에서 무슨 기능인지. 실측 기준 (2026-08-24).

관련: [Boxer](README.md) · [RP4TD-M 수신기](../../receivers/radiomaster-rp4td-m/README.md) · [BRINGUP.md](../../../BRINGUP.md)

## 하드웨어 구성 (radio.yml `switchConfig` / `potsConfig`)

**단수를 착각하기 쉽다.** 3단은 SB·SC 둘뿐이다.

| 입력 | 종류 | 비고 |
|---|---|---|
| SA | **2POS** | 2단 — 중간 없음 |
| SB | 3POS | 3단 |
| SC | 3POS | 3단 |
| SD | **2POS** | 2단 — 중간 없음 |
| SE | 2POS | 2단 |
| SF | **TOGGLE** | 모멘터리 — 손 떼면 복귀. **KILL 같은 래치 기능에 부적합** |
| P1 | with_detent | 다이얼 (노치) |
| P2 | with_detent | 다이얼 (노치) |
| **P3** | **multipos_switch** | **6단 스위치** — 6슬롯 비행모드에 그대로 대응 |

## 스위치 위치별 RC 값 — ⚠️ 위가 1000, 아래가 2000

**직관과 반대이므로 주의.**

| 물리 위치 | 3단(SB·SC) | 2단(SA·SD·SE) |
|---|---|---|
| **가장 위** | **1000** | **1000** |
| 가운데 | 1500 | — |
| **가장 아래** | **2000** | **2000** |

**SA·SB·SC·SD 4개 스위치로 교차 검증 완료** (2026-08-24). 스위치를 아래로 내릴수록 값이 커진다.

검증 실측 — 4개를 서로 다른 위치에 두고 한 번에 관측:

| 스위치 | 물리 위치 | 채널 | 값 |
|---|---|---|---|
| SC | 위 | CH9 | **1000** |
| SB | 중간 | CH6 | **1500** |
| SA | 아래 | CH5 | **2000** |
| SD | 아래 | CH7 | **2000** |

같은 시점 FC 보고: `main=2 (ALTCTL)` — SB 중간(1500)이 슬롯3·4에 매핑되는 것도 함께 확인됐다.

> PX4 는 스위치형 파라미터(`RC_MAP_*_SW`)에서 **1500 초과를 ON** 으로 본다.
> 즉 **아래로 내리면 발동**, 위가 평소 위치다.
>
> ⚠️ **가운데(1500)는 쓰지 마라.** PX4 임계값 경계라 진동·노이즈로 ON/OFF 가 깜빡일 수 있다.
> 3단 스위치를 2단처럼 위/아래만 쓴다.

## 채널 배정

| 스위치 | 채널 | 박서 믹스명 | FC 파라미터 | 위(1000) | 아래(2000) |
|---|---|---|---|---|---|
| **SA** | CH5 | ARM | `RC_MAP_ARM_SW=5` | 해제 | **ARM** |
| **SB** | CH6 | MOD | `RC_MAP_FLTMODE=6` | STABILIZED | POSCTL |
| **SD** | CH7 | BP | `RC_MAP_TRANS_SW=7` | 멀티로터 | 고정익 전환 |
| **SE** | CH8 | TUR | `RC_MAP_KILL_SW=8` | 해제 | **KILL** |
| **SC** | CH9 | RTL | `RC_MAP_RETURN_SW=9` | 해제 | **RTL** |

스틱: `Ail`→CH1, `Ele`→CH2, `Thr`→CH3, `Rud`→CH4 (각각 `RC_MAP_ROLL/PITCH/THROTTLE/YAW`).

### SB 비행모드 3단

`COM_FLTMODE` 슬롯이 6개인데 3단 스위치라 2슬롯씩 묶인다.

| SB | CH6 | 슬롯 | 모드 |
|---|---|---|---|
| 위 | 1000 | 1·2 | **STABILIZED** |
| 가운데 | 1500 | 3·4 | ALTCTL |
| 아래 | 2000 | 5·6 | POSCTL |

## RTL 스위치 (SC) — 2026-08-24 추가

### 박서 쪽 설정

`MODELS/model00.yml` 직접 편집으로 추가했다. USB Storage 모드에서 편집 후 **재부팅해야 적용**된다
(EdgeTX 는 모델을 RAM 에 들고 있다가 종료 시 SD 에 쓰므로, 켜진 채로 편집하면 덮어써진다).

```yaml
# expoData 에 추가
 -
   mode: 3
   srcRaw: "SC"
   weight: 100
   chn: 8            # I8

# mixData 에 추가
 -
   destCh: 8         # CH9
   srcRaw: "I8"
   weight: 100
   name: "RTL"
```

### FC 파라미터

```
RC_MAP_RETURN_SW = 9
RTL_RETURN_ALT   = 5.0    # 이전 60.0
RTL_DESCEND_ALT  = 5.0    # 이전 30.0
```

### 작동 검증 (2026-08-24)

SC 를 아래로 내리자 FC 가 즉시 전환:

```
CH9 = 2000
custom_mode = 0x05040000   main=4 (AUTO)  sub=5 (RTL)
```

## RTL 동작 — 알아둘 것

| 파라미터 | 값 | 의미 |
|---|---|---|
| `RTL_TYPE` | 1 | 홈으로 **직선 복귀** |
| `RTL_RETURN_ALT` | 5 m | 복귀 고도 (**홈 지면 기준 상대**) |
| `RTL_DESCEND_ALT` | 5 m | 하강 후 대기 고도 |
| `RTL_CONE_ANG` | 45° | 홈 근처면 복귀 고도를 낮춤 |
| `RTL_MIN_DIST` | 10 m | 이내면 상승 없이 바로 착륙 |
| `RTL_LAND_DELAY` | 0 | 도착 즉시 착륙 |
| `NAV_RCL_ACT` | 2 | RC 신호 두절 시 자동 RTL |

**순서**: 현재 비행 중단 → 복귀 고도로 이동 → 홈 좌표로 직선 이동 → 하강 → 착륙.
고정익 모드였다면 먼저 멀티로터로 전환(`VT_B_TRANS_DUR` 10초)하며 그동안 위치가 흐른다.

### 콘 각도 — 항상 5m 까지 올라가지 않는다

`RTL_CONE_ANG=45°` 라 홈을 꼭짓점으로 하는 원뿔 안에 있으면 복귀 고도가 줄어든다.
복귀 고도 = `min(RTL_RETURN_ALT, 홈까지_수평거리 × tan45°)`.

| 홈까지 거리 | 복귀 고도 |
|---|---|
| 3 m | 3 m |
| 5 m 이상 | 5 m |

### 🔴 고도 5m 의 제약

**RTL 은 직선 복귀이며 지형·장애물 회피가 없다.** 5m 는 여유가 거의 없다.

- **개활지에서, 육안 감시 가능 범위에서만** 사용
- 홈까지 경로에 나무·전선·건물·사람이 없는지 사전 확인
- **비행 반경이 커지거나 시야 밖으로 나가는 임무라면 고도를 다시 올려야 한다**

60m(기본값)로 두면 저고도 근거리 테스트에서 오히려 위험해 5m 로 낮췄다 — 5m 호버 중
RTL 을 걸면 60m 까지 치솟기 때문. **운용 범위가 바뀌면 이 값도 같이 바꿔야 한다.**

### 홈 고도는 상대값

`RTL_RETURN_ALT` 는 **홈(arm 지점) 지면 기준 상대고도**다. 해발이 아니다.
지형 추종도 없으므로, **홈보다 높은 지형 위를 지날 때 실제 지상고도가 줄어든다.**
산악·경사지에서는 경로를 미리 따져야 한다.

## 자동미션 스위치 — 검토 중

**PX4 에는 미션 전용 스위치 파라미터가 없다.** `RC_MAP_ARM_SW`/`KILL_SW`/`RETURN_SW`/`TRANS_SW`
는 있어도 `RC_MAP_MISSION_SW` 는 존재하지 않는다. 미션 진입은 **`COM_FLTMODE` 슬롯을 통해서만**
가능하므로, `RC_MAP_FLTMODE` 가 가리키는 채널값이 해당 슬롯 범위에 들어와야 한다.

PX4 슬롯 경계 (채널값):

```
1000~1160 슬롯1   1160~1320 슬롯2   1320~1480 슬롯3
1480~1640 슬롯4   1640~1800 슬롯5   1800~2000 슬롯6
```

### 방향: P3(6단)로 미션만 추가

SB 의 STAB/ALTCTL/POSCTL 은 그대로 두고, **P3 를 6번으로 돌렸을 때만** 슬롯6에 진입시킨다.
평소 P3 는 1번에 둔다.

박서 CH6 믹스에 조건부 항목을 얹는 방식:

```
CH6 믹스1:  SB   weight 조정   (기존)
CH6 믹스2:  MAX  mltpx=REPLACE  swtch=<P3 6번 조건>
```

REPLACE 라 P3 6번일 때만 SB 를 덮어쓰고, 1~5번이면 SB 값이 그대로 나간다.

⚠️ **SB weight 축소가 필요하다.** 현재 SB 아래가 2000 이라 이미 슬롯6에 닿는다.
`COM_FLTMODE6` 를 AUTO_MISSION 으로 바꾸면 **SB 를 아래로 내려도 미션이 걸린다.**
SB 최대값을 1750(슬롯5) 정도로 눌러 슬롯6을 P3 전용으로 비워야 한다.

| 입력 | 목표 CH6 | 슬롯 | 모드 |
|---|---|---|---|
| SB 위 | 1000 | 1 | STABILIZED |
| SB 중간 | 1375 | 3 | ALTCTL |
| SB 아래 | 1750 | 5 | POSCTL |
| **P3 6번** | **2000** | **6** | **AUTO_MISSION** |

### 검토 후 버린 안

| 안 | 버린 이유 |
|---|---|
| SE 에 미션, KILL 을 SF 로 이동 | SF 가 **TOGGLE(모멘터리)** 이라 KILL 부적합. KILL 위치 변경은 급박한 상황의 근육 기억을 어긋나게 하므로 그 자체가 위험 |
| S2(P1/P2) 다이얼 80% 임계 | 동작은 가능하나 P3 6단이 슬롯 6개와 1:1 대응해 더 단순 |
| QGC 에서 Start Mission | 스위치 불필요하고 가장 안전. 노트북 2대 운용이면 실용적 — **대안으로 유효** |

### 🔶 남은 작업

- P3 6단 각 위치의 실측값 미확보 (FC 연결 필요)
- SB weight 조정값 계산
- 박서 논리스위치 + 믹스 편집
- `COM_FLTMODE6 = AUTO_MISSION` 설정
