# print3d — SHADE01 3D 프린터 출력 모형

콕핏 화면용 3D 모델을 **출력 가능한 입체**로 바꿔 책상 위 모형을 뽑는다.
아직 준비 단계다 — 폴더·지침만 있고 출력용 스크립트는 없다 (2026-09-27).

## 원본과의 관계

- 형상의 정본은 [`web/model/striver.py`](../web/model/striver.py) (Blender 4.5 스크립트) 하나다.
  출력용 형상을 따로 그리지 않는다 — 원본을 불러와 **가공만** 한다. 실기 치수가
  바뀌면 원본만 고치면 양쪽이 같이 따라온다.
- 🔴 **출력 때문에 원본을 고치지 마라.** 콕핏(`web/public/cockpit.js`)이 노드 이름
  (`rotor_*`, `aileron_*`, `hatch_*`, `bay_*` …)으로 부품을 찾는다. 이름·구조를 바꾸면
  화면에서 로터·조종면·탑재칸이 조용히 빠진다.
- 원본은 실행하면 끝에서 `.glb` 를 내보낸다(`striver.py` 665행 부근). 출력 스크립트가
  형상만 쓰려면 이 부분을 건너뛸 방법을 정해야 한다 — 아래 「정할 것」.

## 구조

```
print3d/
  README.md     이 문서 — 결정·규칙·절차
  print.py      (예정) striver.py 형상 → 출력용 가공 → STL/3MF
  out/          (예정) 출력 파일 — git 에 안 넣는다 (.gitignore)
```

돌리는 법 (예정, 원본과 같은 형식):

```bash
~/tools/blender-4.5.9-linux-x64/blender -b -P print3d/print.py -- print3d/out/shade01_1-10.stl
```

## 기본 축척 — 1:10

| 축척 | 날개폭 | 길이 | 프로펠러 ⌀ | 출력판 |
|---|---|---|---|---|
| 1:12 | 175 mm | 100 mm | 36 mm | 180 mm 급, 레진 |
| **1:10** | **210 mm** | **120 mm** | **43 mm** | **220~256 mm FDM, 통째로** |
| 1:8 | 262 mm | 150 mm | 54 mm | 256 mm 판에 대각선 |
| 1:5 | 420 mm | 240 mm | 86 mm | 날개 분할·조립 |

원본 치수: 날개폭 2,100 mm · 동체 1,200 mm · 로터 반지름 0.215 m (`striver.py`).

## 가공 규칙

원본은 화면용이라 그대로는 출력이 안 된다. 출력 스크립트가 할 일:

| 대상 | 원본 상태 | 처리 |
|---|---|---|
| `bay_*` | 클릭 영역 (안 보이는 상자) | 뺀다 |
| `in_*` | 동체 안 부품 (배터리·FC·ESC …) | 뺀다 |
| `registration`, `name` | 두께 0 인 글자 평면 | 뺀다 (스티커) 또는 양각 0.3~0.5 mm |
| `hinge_*`, `servo_*`, `panel_seam_*` | 1.5 mm 판·홈 선 | 뺀다 — 1:10 에서 0.15 mm |
| `root_band_*`, `center_panel_*`, `band` | 표면에 덧씌운 얇은 껍데기, 끝이 열린 관 | 뺀다 (도색으로) |
| 프로펠러 날 | 두께 4 mm → 1:10 에서 0.4 mm | 최소 두께까지 부풀리거나 빼고 모터까지만 |
| 나머지 | 부품마다 따로 겹친 메시 | 하나로 합친다 (Boolean union 또는 Voxel remesh) |

로터 원판(회전 표시)은 `cockpit.js` 가 화면에서 붙이는 것이라 모델에 없다.

**최소 두께 (출력 축척 기준):** FDM 1.2 mm · 레진 0.6 mm.
이보다 얇으면 부풀리거나 뺀다.

## 절차

1. `print.py` 로 원본 형상을 만들고 위 규칙대로 가공한다
2. 축척을 적용한다 (Blender 단위 m → 출력 mm: 1:10 이면 ×100)
3. Blender **3D Print Toolbox** 로 검사한다 — 닫힌 입체(manifold)인지, 최소 두께 미달이 없는지
4. STL/3MF 로 `out/` 에 내보낸다
5. 슬라이서에서 방향·서포트를 잡는다 — 통째 출력이면 배를 아래로
6. 한 번 뽑아 보고 깨진 부위를 이 문서 「출력 기록」에 적는다
